# ⚡ EV Market Analysis Dashboard – India

## Overview

This project presents an interactive Excel dashboard analyzing the growth and adoption of Electric Vehicles (EVs) in India. The dashboard provides insights into market trends, vehicle categories, regional adoption patterns, and overall industry performance.

The objective of this project is to transform raw EV market data into meaningful business insights that can support strategic decision-making and market analysis.

---

## Project Objectives

- Analyze India's EV market growth trends
- Track EV adoption across different segments
- Identify high-growth markets and regions
- Evaluate industry performance indicators
- Generate actionable insights through visualization

---

## Key Insights

- Category-wise vehicle analysis
